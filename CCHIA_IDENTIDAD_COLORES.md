## 🎨 Gradientes Utilizados

### **Gradiente Teal (Acento)**
```css
background: linear-gradient(to right, #1FB6A6, #4EE3D3);
```
**Uso**: Botones de acción, highlights, elementos interactivos

### **Gradiente Azul Institucional**
```css
background: linear-gradient(to right, #0A2A66, #0D3380);
```
**Uso**: Headers, secciones hero, elementos de marca

### **Gradiente Fondo Light**
```css
background: linear-gradient(to bottom, #FFFFFF, #F2F4F8, #FFFFFF);
```
**Uso**: Fondos de secciones en light mode

### **Gradiente Fondo Dark**
```css
background: linear-gradient(to bottom, #081C45, #0A2A66, #081C45);
```
**Uso**: Fondos de secciones en dark mode

## 🎯 Aplicación de Colores por Componente

### **Navbar**
- **Light Mode**: Fondo `#FFFFFF`, Texto `#0A2A66`, Hover `#1FB6A6`
- **Dark Mode**: Fondo `#081C45`, Texto `#E5EAF3`, Hover `#4EE3D3`

### **Hero Section**
- **Light Mode**: Fondo gradiente `#FFFFFF → #F2F4F8`, Texto principal `#0A2A66`
- **Dark Mode**: Fondo gradiente `#081C45 → #0A2A66`, Texto principal `#E5EAF3`
- **Acento**: Teal `#1FB6A6` en ambos modos

### **Cards de Eventos**
- **Light Mode**: Fondo `#FFFFFF`, Borde `#D9DEE8`, Texto `#0A2A66`
- **Dark Mode**: Fondo `#0A2A66`, Borde `#1E3A8A`, Texto `#E5EAF3`
- **Botón Inscribirse**: Gradiente teal con texto adaptativo

### **Carrusel de Aliados**
- **Logos**: Efecto grayscale → color en hover
- **Fondo Cards**: `#FFFFFF` (light) / `#0A2A66` (dark)
- **Borde**: `#D9DEE8` (light) / `#1E3A8A` (dark)
- **Hover**: Borde cambia a `#1FB6A6` / `#4EE3D3`

### **Footer**
- **Light Mode**: Fondo `#F2F4F8`, Texto `#4A5F8A`
- **Dark Mode**: Fondo `#081C45`, Texto `#AAB4C8`
- **Links**: Hover a `#1FB6A6` (light) / `#4EE3D3` (dark)

## 📐 Proporciones de Uso Recomendadas

### **Light Mode**
- **60%**: Blanco `#FFFFFF` (fondos principales)
- **30%**: Azul institucional `#0A2A66` (textos, elementos de marca)
- **10%**: Teal `#1FB6A6` (acentos, CTAs, interacciones)

### **Dark Mode**
- **60%**: Azul oscuro `#081C45` (fondos principales)
- **30%**: Teal `#1FB6A6` (primario, acentos, CTAs)
- **10%**: Azul medio `#0A2A66` (fondos secundarios, cards)

---

## ✨ Principios de Diseño

### **Contraste**
- Siempre mantener ratio de contraste mínimo 4.5:1 para texto
- Usar `#0A2A66` sobre `#FFFFFF` en light mode (ratio: 12.6:1) ✅
- Usar `#E5EAF3` sobre `#081C45` en dark mode (ratio: 13.8:1) ✅

### **Jerarquía Visual**
1. **Primario**: Azul institucional `#0A2A66` (light) / Teal `#1FB6A6` (dark)
2. **Secundario**: Teal `#1FB6A6` (light) / Azul medio `#0A2A66` (dark)
3. **Terciario**: Grises para fondos y textos auxiliares

### **Accesibilidad**
- Todos los colores cumplen con WCAG 2.1 AA
- Textos principales cumplen con AAA
- Botones tienen estados hover/focus claramente diferenciados

---

## 🔄 Transiciones de Tema

### **Elementos que Cambian**
- Fondos: Blanco → Azul oscuro
- Textos: Azul oscuro → Blanco/Gris claro
- Primario: Azul → Teal
- Bordes: Gris claro → Azul medio

### **Elementos que se Mantienen**
- Teal `#1FB6A6` como acento de innovación
- Gradientes teal en botones de acción
- Logos de aliados (solo efecto grayscale)

---

## 📱 Responsive & Adaptativo

Los colores se mantienen consistentes en todos los breakpoints:
- **Mobile** (< 640px): Misma paleta
- **Tablet** (640px - 1024px): Misma paleta
- **Desktop** (> 1024px): Misma paleta

Solo cambian tamaños, espaciados y layouts, nunca los colores.
