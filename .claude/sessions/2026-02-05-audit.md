## Trade-offs Considered

1. **Penalty formula adjustment**
   - Option A: Per-issue penalties (CRITICAL=-10 each) -> Score would be negative
   - Option B: Proportional caps -> Chosen, more balanced
   - Reasoning: Score should reflect overall health, not just issue count

2. **Duplication handling**
   - Option A: Count as efficiency loss only
   - Option B: Also flag as MEDIUM issues
   - Chosen: Both (efficiency score AND issue tracking)

3. **Cross-reference broken count**
   - 1 broken reference found
   - Severity: Flagged as area concern, not separate CRITICAL issue
